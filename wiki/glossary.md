# Глоссарий

Единый словарь терминов проекта. Если вводишь новый термин — добавляй сюда, чтобы он не
переизобретался в следующем чате под другим именем.

## Игровые термины

| Термин | Значение |
|---|---|
| Шасси | Конкретная модель робота: сочетание тоннажа, реактора, силового каркаса и типа локомоции + навешенное вооружение |
| Тоннаж | Полная масса робота в тоннах; определяет весовой класс |
| Весовой класс | Лёгкий (20–35т) / Средний (40–55т) / Тяжёлый (60–75т) / Штурмовой (80–100т), с шага 49 одна разбивка на весь проект, см. [design/mechs/classification.md](design/mechs/classification.md). Не путать с классом десантного корабля |
| Реактор | Компонент шасси, задающий энергоёмкость — сколько вооружения и оборудования робот может обслуживать по теплу/энергии |
| Силовой каркас (кратко: Каркас) | Компонент шасси, определяющий, сколько массы брони/обвеса можно навесить сверху. Официальный термин, заменяет прежнее рабочее название "несущий скелет" |
| Гуманойдный / негуманойдный | Тип локомоции робота: двуногий (H, каркасы F1–F3) или обратный сустав (N, каркасы F2–F3). Ось косметическая: характеристики платформы от неё не зависят |
| Маркировка шасси | Буквенно-цифровой код вида `{локомоция}{тоннаж}-{реактор}{каркас}`, напр. `H55-R3F2` |
| MP (Movement Points) | Очки движения за ход: обычный ход / бег / прыжок, зависят от весового класса |
| ЦТ / ПТ / ЛТ | Центральный / правый / левый торс (зоны попадания) |
| ПР / ЛР | Правая / левая рука (зоны попадания) |
| ПН / ЛН | Правая / левая нога (зоны попадания) |
| Уровень (клетки) | Высота или глубина клетки, целое −5…+5. Отрицательный = вода/низина. Задаёт цену перехода, видимость, урон от падения |
| Ребро (клетки) | Граница между двумя соседними клетками. Несёт признаки `CLIFF`, `WALL`, `GATE`, `BRIDGE`; хранится один раз на две клетки. Река с шага 9c сюда не входит — это рельеф `вода` на клетке, не признак ребра |
| Оверлей | Динамический слой поверх рельефа: дым, пожар, лёд. Появляется и исчезает по ходу боя |
| Высота объекта | Сколько уровней объект добавляет поверх уровня клетки (лес 2, здание 1…4). Используется только для видимости |
| Blip | Уровень обнаружения 1: известно, что на гексе кто-то есть, без деталей |
| Silhouette | Уровень обнаружения 2: виден весовой класс |
| Identified | Уровень обнаружения 3: известны конкретное шасси и вооружение |
| Навык | Способность пилота, уровень 1–10, больше — лучше. Пять кокпитных и пять личных |
| Ступень мастерства | Ярлык уровня: Новобранец 1–2, Обученный 3–4, Ветеран 5–6, Элита 7–8, Легенда 9–10 |
| Потолок таланта | Индивидуальный максимум персонажа по каждому навыку, 4–10. Задаётся при создании из сида и происхождения |
| Намерение / Исполнение | Два этапа разрешения действия: сначала бросок «получилось ли», затем проверка, не сорвал ли пилот удавшееся |
| Срыв | Провал проверки исполнения: попадание становится промахом, маршрут не дойден, прыжок кончается жёстким приземлением. Зависит от Хладнокровия |
| Собранность | Обратный эффект при Хладнокровии 8+: промах ровно на единицу может стать попаданием |
| Подтверждение кокпита | Второй d6 после выпавшей «головы»: 1–2 — попадание в кабину, 3–6 — выстрел уходит в торс. Опускает долю попаданий в кокпит с 1/6 до ~1/18 |
| Засветка | Нижний уровень контакта: «на этом гексе кто-то есть». Даёт сенсор, рельеф ей не мешает; ни класса, ни вооружения не видно |
| Силуэт | Средний уровень контакта: виден весовой класс. Требует прямой видимости |
| Опознан | Верхний уровень контакта: известны шасси, вооружение и состояние. Требует видимости и дистанции опознания либо двух ходов, в которые противник открывал огонь |
| Пробитие кокпита | Броня головы пробита. 1d6: 5–6 — выстрел пришёлся в остекление, пилот потерян без броска на катапультирование |
| Сквозной урон | Попадание в уже разрушенную зону уходит в торс, а не пропадает |
| Запас зоны | Броня + структура. Именно он, а не «толщина брони», задаёт порядок отказа зон |
| В строю / Выбыл / Катапультировался / Потерян | Четыре состояния пилота. Выбывший возвращается после лечения, катапультировавшийся — всегда, потерянный — нет |
| Катапультирование | Уход пилота из машины. Основная механика выживания: разрушенный торс отпускает всегда, риск живёт в ранении при приземлении |
| Уравнение массы | `тоннаж = реактор + каркас + броня + навеска`. Из него выводятся броня и структура шасси, а не подбираются руками |
| Платформа | Всё, что следует из четвёрки (техбаза, тоннаж, тир реактора, тир каркаса) до навески |
| Тир реактора (R1..R5) | Покупает подвижность массой. Тепло от тира не зависит |
| Тир каркаса (F1..F5) | Меняет массу на слоты: легче каркас — больше груза, меньше места |
| Слот | Место под оборудование в зоне. Масса решает, что несёшь; слоты — куда ставишь |
| Ячейка | Слот в боевой модели: то, по чему бьёт крит. 58 на робота, 21 из них занята несъёмным |
| Критическое попадание | Бросок при пробитой броне: механическое оружие 30 %, лучевое 15 %. Ломает то, что стоит в выпавшей ячейке, — или ничего, если ячейка пуста |
| Детонация боезапаса | Урон пачки в её зону по обычным правилам. Пулемётная пачка (400) уничтожает любую машину, снаряды Гаусса (0) не детонируют |
| CASE | Защита от детонации: обычный не пускает избыток в соседнюю зону, CASE II гасит взрыв внутри зоны. У кланов встроен бесплатно |
| Обесточен | Аварийное отключение реактора при тепле 28. Ход пропущен, дальше машина включается сама, без броска |
| Трофей | Машина, выбитая из боя с целыми торсом и кокпитом. Не обломки, а прибавление к отряду — ради этого криты и заводились |
| Обездвиженность | Оторвана нога или разрушен гироскоп (2-й крит). Машина выведена из боя так же, как при разрушенном торсе: не встаёт, не стреляет, пилот уходит |
| Техбаза | Сфера (`is`) или Кланы (`clan`). Кланское железо строго лучше — асимметрия намеренная |
| Круг Равных | Клановая рукопашная дуэль за оспаривание должности, решения или имени. Использует личные навыки |
| Испытание Позиции | Клановый бой, определяющий звание воина при выпуске |
| Испытание Кровного Имени | Турнир на 32 претендента за право носить кровное имя |
| Тепло | Шкала 0–30, растёт от движения/стрельбы, штрафует попадание и подвижность на порогах. Пороги 14/19/25: отключение, детонация, ранение пилота |
| Альфа-страйк | Залп из всего оружия за ход. Стволы бьют по очереди: тепло копится после каждого, и каждый выстрел бросает свою зону |
| Тепловая дисциплина | Насколько бот переоценивает цену нагрева. Ось личности: осторожный держит запас, агрессивный жжёт до порога |
| Зеллбригген | Клановый дуэльный кодекс боя (появляется в кампании за клан) |
| Batchall | Клановое объявление сил перед боем |
| Отношение | Ось репутации: как конкретная фракция относится к отряду, −100…+100 |
| Известность | Ось репутации: насколько об отряде вообще слышали, 0…100. Задаёт уровень доступных контрактов |
| Надёжность | Ось репутации: доверие к отряду, 0…100. Задаёт предоплату и условия. Не восстанавливается затуханием |
| Честь | Отдельная ось репутации для кланов: соблюдение batchall и зеллбриггена. Основа карьеры в кампании за клан |
| Личность бота | Именованный вектор весов оценки в JSON (агрессивный, осторожный, снайпер) — задаёт манеру боя без отдельного кода |
| Тикер | Симуляция глобального мира на весовых правилах: фракции, фронт, экономика. Он же источник контрактов |
| Класс исполнения (Quality Class) | Качество узла: Заводской (A), Армейский (B), Серийный (C), Полевой (D), Хлам (F). Задаёт массу, цену и надёжность узла; основа ремонта, рынка и характера противников |
| Износ (Wear) | Накопление усталости узлов машины (0..100%) в ходе походов и боёв; снимается обслуживанием на стапеле ангара |
| Комплектность (Outfit) | Доля фактически смонтированной брони и вооружения от паспортного проекта платформы (отличие от износа и повреждений) |
| Задачи боя (Objectives) | Условия победы в тактическом бою: гарнизон (выстоять 8 ходов), разведка (вывести 50% сил), рейд (вывести 65%), оборона (удержать 11 ходов), штурм (вывести всех) |
| Достаток / Снабжение (Prosperity / Supply) | Мера экономической мощи мира и фракции; задаёт доступные классы исполнения, силу частей и надбавку к оплате |
| Разорение (Ruin) | Степень ущерба планете от боевых действий (0..1); снижает доход владельца и ухудшает класс рынка |
| Лояльность (Loyalty) | Насколько мир роты считает державу своей (0..100, шаг 85): старт по способу получения, множит доход и мощность мира (0.5 + лояльность / 200); ниже 15 — восстание. Есть только у миров роты |
| Восстание (Revolt) | Мир роты с лояльностью ниже порога: на его бирже — работа «подавить восстание» против ополчения прежнего владельца; без победы за 6 декад мир отходит прежнему владельцу |
| Работа дома | Контракт на бирже мира роты: держава себе не платит — ни гонорара, ни аванса, ни неустойки; победа поднимает лояльность, против врага войны идёт в счёт войны |
| Такт войны / Сектор фронта | Десятидневный цикл стратегической симуляции; фракции копят фонды, двигают линию фронта и захватывают миры |
| Напряжённость участка | Накопленные военные фонды сторон на приграничном участке; поднимает живую вражду и генерирует опасные контракты |
| Быстрый расчёт боя (Fast Resolve) | Мгновенный расчёт боя чистой функцией ядра без визуализации; сохраняет детерминизм и калиброван по потерям и исходам полного боя |
| Рейтинг отряда (Company Rating / MRBC) | Комплексная мера боевой мощи роты (класс × тоннаж × комплектность × выучка экипажа) |
| Склад и стапели (Warehouse / Bays) | Инфраструктура ангара: вместимость запаса деталей и параллельные слоты под ремонт и переоснащение |
| Ячейки ангара (Hangar slots) | Сколько машин рота держит и выводит за раз. Корабль вмещает 8 / 16 / 24 (Леопард / Юнион / Оверлорд), сразу открыта половина; остальные выкупаются по одной в экране ангара — по той же цене и в тот же срок, что стапель с тем же номером. Новый корабль открывает свой минимум, выкупленное не теряется. |
| Десантный корабль (DropShip) | Базовый транспорт и мобильная операционная база роты (классы Leopard, Union, Overlord). Задаёт потолок парка боевых машин и предел расширения ремонтных стапелей цеха |
| Верфь (Shipyard) | Орбитальная инфраструктура развитого мира (космопорт A, столица фракции или индустриальный арсенал с космопортом B/C), где возможна покупка и модернизация десантных кораблей |
| Заказ узла (OrderPart) | Заказ фабричного узла по СПЕЦИФИКАЦИИ — узел, тоннаж, тир и класс задаёт игрок — с доставкой через время перелёта. Реактор и каркас заказываются связкой: один счёт, один день прибытия. Мир решает не «есть ли это», а почём и как быстро: наценка и срок берутся из класса системы и видны на карте, с периферии не возят вовсе (шаг 45) |
| Обитаемость (Habitability) | Свойство биома: сдвиг десятичного логарифма населения плюс потолок населения. Разводит миры, ГДЕ ЖИВУТ (умеренный, джунгли), и миры, ГДЕ ДОБЫВАЮТ (вулканический, лунный) |
| Богатство недр (Richness) | Свойство биома, 0..1: прибавка к военной промышленности мира. Гарнизон и техуровень от неё НЕ зависят — рудник не крепость, и богатый рудой слабо защищённый мир существует ради набегов |
| Фокус мира (World Focus) | Одна специализация планеты из пяти: житница, сырьевой комплекс, индустриальный арсенал, торговая метрополия, мир-крепость. Перераспределяет мощность, доход, содержание и оборону мира; меняется раз в игровой год за деньги |
| Естественный фокус (Natural Focus) | Фокус, который выводится из профиля мира порогами и без единого броска. В снимке не хранится; дельта пишет только отклонение от него |
| Промышленная мощность (Industrial Capacity) | Пропускная способность державы: сколько машин она способна построить за декаду. Задаёт целевую численность армии и потолок её восстановления; падает вместе с разорением заводов. Не склад — накопить её нельзя |
| Домен игрока (Player Domain) | Миры, которыми владеет рота. Их доход идёт в кассу, а не в казну фракции; их можно переделывать и развивать, их жгут набегами, но отнять их до фазы 3 нельзя |
| Живая вражда (Live Enmity) | Вражда пары фракций, прочитанная из матрицы отношений кампании, а не из статичной таблицы 3053 года. Точное обращение начального отношения: `вражда = (1 − отношение) / 2`. По ней с шага 26 считаются участки фронта, их вес, раскладка военного фонда и напряжённость биржи |
| Полоса отношения (Relation Band) | Слово вместо числа для пары фракций: война, вражда, холод, нейтралитет, согласие, союз. Участок фронта порождают только первые три |
| Дань (Tribute) | Первая ступень подчинения: победитель не отнимает мир, а облагает его долей дохода. Владелец, содержание и гарнизон остаются прежними. Срок конечен и требует подтверждения силой |
| Данник (Tributary) | Держава, чьи миры платят дань другой. Флаг, армию и самоуправление сохраняет |
| Протекторат (Protectorate) | Вторая ступень: держава признаёт сюзеренитет соседа, отдаёт долю дохода в его военный фонд и не воюет ни с ним, ни с его остальными вассалами. Вырастает из дани и распадается вместе с ней |
| Сюзерен / Вассал (Suzerain / Vassal) | Стороны протектората. Вассала вассала не бывает; у сюзерена есть потолок числа вассалов, и оба ограничения — предохранители от каскада, в котором один сюзерен собрал бы карту |
| Договор пары (Pact) | Третья ступень: перемирие на срок (пара не воюет) или торговый договор (обе стороны получают прибавку к доходу). Заключается на пару, а не на направление |
| Роспуск приготовлений (Fund Release) | Возврат военного фонда в казну: целиком — когда направление перестало быть враждебным, долей за декаду — когда на нём не стреляли. Именно этим шаг 26 закрыл долг 21a: фонд перестал расти без предела |
| Ступень дипломатии (Diplomacy Tier) | Что рота может делать в политике: 0 — наёмник (ничего), 1 — землевладелец (договоры с соседями, выкуп дани), 2 — держава (обложить данью, принять вассала). Гейтится числом своих миров и осями репутации |
| Ополчение (Militia) | Первый эшелон армии: гарнизон планеты, выведенный из её населения и военной промышленности. **Никуда не летает** и держит оборону мира снизу. Это тот же `garrison` 0..5 из профиля, названный своим именем шагом 27 |
| Полевые полки (Field Regiments) | Второй эшелон: машины, которые перебрасываются на фронт. Хранятся не по мирам, а по направлениям |
| Театр (Theater) | Полевые полки, стянутые на одно направление: «Дэвион против Куриты — 740 машин». Хранится тем же ключом, что военный фонд (откуда → против кого), и так же разрежённо. Разбитый театр обваливает одно направление, а держава остаётся жива |
| Резерв (Reserve) | Машины, ещё не отправленные ни на одно направление: выход производства. Боями не тратится; вся армия державы — это резерв плюс все её театры |
| Подъёмная сила (Lift) | Сколько **машино-прыжков** за декаду держава способна перевезти. Выводится из классов космопортов своих миров плюс канонический флот по виду державы. Держава с портами класса A возит полки, держава с грунтовыми площадками — нет |
| Плечо (Haul) | Расстояние в прыжках от столицы владельца до ближайшего участка направления. Перевезти одну машину на N прыжков стоит N машино-прыжков, поэтому дальний фронт питается медленнее ближнего сам собой. Оно же входит в содержание мира и делает дальние владения дороже |

Такой контракт не платит **ничего**: ни гонорара, ни аванса, ни неустойки, ни доли трофеев. Плата — отношение нанимателя, и растёт она со сложностью работы. Судьбу сектора искупление не решает.<br><br>**На каких планетах какая работа**:<br>• **Число предложений** зависит от развития мира: столица (6), промышленный (5), развитый (4), аграрный (3), захолустье/периферия (2). Станция HPG даёт +2 контракта, чёрный рынок +1.<br>• **Где искать войну**: контракты требуют врагов в пределах 2 прыжков. В тылу и против пиратов идут патрули, гарнизоны и разведка. Оборона (вражда от 0.60) и Штурм (от 0.75) возникают только на горячих приграничных рубежах, куда державы стянули военные фонды.<br>• **Масштаб сил**: патруль (1–2 машины), копьё (3–4), усиленный отряд (6–8), рота (10–12), батальон (16–24). Крупный бой требует укреплённого гарнизона планеты (от 3–4) и высокого напряжения сектора.<br><br>**Что такое разведка**:<br>• **Миссия «Разведка»** — контракт с долевой задачей (50 % потерь врага), где отряду не нужно зачищать поле целиком.<br>• **Достоверность сводки (разведка %)** — насколько точны оперативные данные нанимателя. Это **не порог, а вероятность ошибиться**: разброс разыгрывается на вылете и симметричен — на поле может оказаться и больше машин, чем обещали, и меньше. Чем ниже достоверность, тем шире возможная ошибка и тем чаще она случается; идеальной сводки в игре не бывает вовсе — потолок 95 %. Что именно возможно на ЭТОМ контракте, видно до подписи: карточка показывает полосу «машин от и до, тоннаж от и до» и отдельной строкой — **шанс, что состав не сойдётся** со сводкой. При достоверности 95 % это около 10 % вылетов, при 62 % — около двух третей.<br>• **Разведка системы** на звёздной карте повышает достоверность данных биржи и раскрывает точный класс исполнения вражеских машин (заводской, армейский и т.д.).<br><br>Подробный разбор механик и формул — [design/campaign/contracts.md](design/campaign/contracts.md). |

## Технические термины

Технический стек и архитектура — [`game_core.md`](../game_core.md), здесь только словарь.

| Термин | Значение |
|---|---|
| `core/` | Ядро правил на TypeScript. Не импортирует ничего из слоя показа (DOM, Canvas, Svelte) — проверяется линтером |
| `render/` | Отрисовка карт на Canvas 2D + общий модуль камеры (пан/зум), один на бой и на звёздную карту |
| `ui/` | Svelte-компоненты: экраны глобального слоя и боевой HUD |
| `sim/` | Headless-прогон боёв в Node без отрисовки: автобой и батч-симуляции баланса |
| `platform/` | Изоляция доступа к файлам и сохранениям: `IndexedDbStorage` в браузере (упаковка в Tauri снята 2026-09-02) |
| `Command` / `CommandResult` | Единственный способ менять `BattleState` и `CampaignState`; результат — `{ ok, events }` либо `{ ok: false, reason }` |
| `BattleEvent` | Событие для проигрывания слоем показа (`moved`, `toHit`, `damaged`, `critical`, `fell`) |
| `enumerateLegalCommands` | Перебор допустимых ходов юнита. Один источник для подсветки в интерфейсе, ИИ и автобоя |
| `Rng` | Детерминированный ГПСЧ с сериализуемым состоянием и именованными потоками (`initiative`, `toHit`, `hitLocation`, `crits`) — основа реплеев и автобоя |
| Поток ГПСЧ | Отдельная последовательность бросков под свою задачу, чтобы новый бросок в правилах не сдвигал все остальные |
| `LosResult` | Отчёт о линии видимости: заблокирована ли, сколько промежуточных лесов, частичное укрытие, преимущество по высоте |
| Ничья на границе | Линия видимости идёт ровно по ребру: из двух гексов берётся мешающий меньше. Симметрично по построению, поэтому A видит B тогда же, когда B видит A |
| `rollExecution` | Единая проверка исполнения для выстрела, движения, прыжка и рукопашной |
| `resolveAttack` | Чистая функция полного разрешения выстрела: состояние не меняет, возвращает новые версии обоих роботов |
| `fastResolve` | Функция быстрого расчёта боя в ядре для симуляции кампании и соперников без запуска пошагового цикла |
| Боевой журнал | Текстовый разбор каждого броска. Живёт в ядре, а не в слое показа: правило «срыв всегда объяснён» — часть механики |
| Батч-прогон | Прогон тысяч боёв в CSV для настройки чисел замерами, а не на глаз (`pnpm sim`, `pnpm camp`) |
| Golden-replay | Тест: сид + журнал команд + хэш финального состояния. Ловит потерю детерминизма |
| Авто-расчёт боя | Прогон `core/` без отрисовки, ИИ с обеих сторон, только итоговый отчёт |
| Снапшот / реплей | Сохранение — снапшот состояния; реплей — сид плюс журнал команд, действителен только для своей `rulesVersion` |
